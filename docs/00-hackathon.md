## 규칙

- 팀 최대 6명, 혼자도 가능. 팀 구성은 워크숍 이후.
- 프로젝트에 **스폰서 제품을 반드시 통합**해야 함. (Daytona 샌드박스가 가장 쉬운 경로)
- 모든 참가자에게 Daytona, Nosana 크레딧 제공.
- 우승 팀은 스폰서 크레딧을 상품으로 받음.

## 심사 기준

1. 완성도: 최소한의 MVP를 출시했는가
2. 혁신성: 아이디어가 혁신적인가
3. 실제 문제 해결: 실제 문제 또는 시장의 명확한 페인포인트를 다루는가
4. 스폰서 제품 활용: 스폰서 제품을 통합했는가

## 스폰서 제품 요약

### Daytona
자율 에이전트용 격리 샌드박스 인프라. 에이전트마다 자체 커널·파일시스템·네트워크·vCPU·RAM·디스크를 가진 컴퓨터를 제공.
- 샌드박스 시작 90–200ms
- 패키지 설치, 프로세스, Git, 컴파일, 브라우저 실행 가능
- Python / TypeScript / Go / Ruby / Java SDK + MCP 서버
- 수천 개 샌드박스 병렬 실행
- 오픈소스(AGPL), Helm 차트로 자체 호스팅 또는 Daytona Cloud

### DNSimple
관리형 DNS 및 도메인 자동화 플랫폼 (도메인 등록·호스팅·DNS 자동화 API).

### Nosana
분산형 GPU 컴퓨트 네트워크. 파인튜닝부터 저지연 실시간 추론까지 온디맨드 GPU.

## 우리 팀 조건 (2026-09-19 기준 결정 사항)

- 주제: KYA (Know Your Agent) — 위임 관계 확인(b) + 거래 시점 행위 검증(c)
- 목표: 수상
- 인원: 2명 (fullstack 1, devops 1)
- 기존 코드 재사용 없이 새로 만든다
- 에이전트는 실제 LLM 기반으로 구현한다
